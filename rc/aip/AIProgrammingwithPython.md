# Beginner Python PCEP Certification Prep

Develop a strong foundation in Python programming for AI, utilizing tools like NumPy, pandas, and Matplotlib for data analysis and visualization. Learn how to use, build, and train machine learning models with popular Python libraries. Implement neural networks using PyTorch. def greetFunction(name):
    if name:
        print(f"Hello, {name}!") # https://fstring.help/cheat/
    else:
        print("Hello, world!")

greetFunction("Alice") # Hello, Alice!
greetFunction("") # Hello, world!

###### While Loops
***

While loops are essential for executing code repeatedly until a specific condition becomes false.

```python
count = 0

while count < 5:
    print("Count:", count)
    count += 1

# Count: 0
# Count: 1
# Count: 2
# Count: 3
# Count: 4
```

While loops provide flexibility for scenarios where the loop run count isn't predetermined, such as waiting for user inputs or processing data until a file's end. 

Mastery of while loops enhances coding efficiency in managing repetitive tasks.

```python
user_input = ""

while user_input.lower() != "exit":
    user_input = input(
		"""
		Enter something (type 'exit' to quit):
		"""
	)
    print("You entered:", user_input)

#
#     Enter something (type 'exit' to quit):
#     something
# You entered: something
# 
#     Enter something (type 'exit' to quit):
#     exit
# You entered: exit
```

Note: only "EXIT" gets processed. 

Since the loop checks `user_input.lower() != "exit"`, entering "EXIT" makes the condition false right after that input (because "EXIT".lower() equals "exit"), so the loop ends before ever asking for "ExiT".

```python
user_input = ""

while user_input.lower() != "exit":
    user_input = input(
		"""
		Enter something (type 'exit' to quit):
		"""
	)
    print("You entered:", user_input)

# 
#     Enter something (type 'exit' to quit):
#     EXIT
# You entered: EXIT
```

with open("text.txt", "r") as input_file:
